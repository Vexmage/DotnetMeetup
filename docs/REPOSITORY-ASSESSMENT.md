## Confirmed architecture

- **Solution and tooling.** [DotnetMeetup.sln](../DotnetMeetup.sln) contains three `net9.0` projects: the ASP.NET Core host in `DotnetMeetup/DotnetMeetup`, the Blazor WebAssembly client in `DotnetMeetup.Client`, and a Razor class library in `DotnetMeetup.Shared`. The host references both projects, and the client references Shared. There is no tracked `global.json`. The machine lists .NET 9 SDKs 9.0.101 and 9.0.102, plus SDKs 7 and 10. The README describes the meetup site and design references but omits setup commands.
- **Hosting and routing.** Server `Program.cs` maps controllers, static assets, Identity endpoints, and the Blazor root with the client assembly and Interactive WebAssembly enabled. `Components/App.razor` chooses Interactive WebAssembly for eligible requests and static server rendering for routes excluded from interactive routing, including account pages. The client configures auth state deserialization and a same-origin HTTP client. `Routes.razor` selects authorizing or ordinary route views, applies `MainLayout`, and focuses the first `h1` on navigation.
- **Pages and layouts.** Client routes are `/` (Home), `/events`, `/shared-resources`, `/contribute`, `/contribute/talk`, and `/forum` (authorized placeholder). The host provides `/Error` and `/Account/*` registration, login, recovery, and management pages. The main shell uses `MainLayout` and `Navbar`; account management has `ManageLayout`. Shared contains event cards, a calendar and picker, tabs, modals, icons, spinners, toasts, and form validation components. The contribution endpoint logs proposals and returns success, with persistence or delivery left as a TODO.
- **Styles and dependencies.** `App.razor` loads Bootstrap, `app.css`, bundled isolated styles, and Font Awesome. LibMan declares Bootstrap 5.3.3. Local SCSS covers variables, fonts, layout and component styles, and home styling. `compilerconfig.json` maps `app.scss` to `app.css`; compiled CSS, Bootstrap assets, Font Awesome, and Roboto fonts are checked in. NuGet references are Microsoft packages declared at 9.0.4, covering Blazor WebAssembly/authentication, Identity, and EF Core providers and tooling.
- **Persistence.** Startup registers EF Core SQLite using the `DefaultConnection` configuration key. `ApplicationDbContext` combines Identity and an `Events` set; one initial migration is tracked. `GET /api/events` returns database events used by Home and Events. SQL Server references and Visual Studio service dependency descriptors exist, but the inspected startup selects SQLite. The configured database location and production persistence are unverified.
